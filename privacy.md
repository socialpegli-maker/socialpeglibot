# Privacy Policy per SocialPegliBot

Ultimo aggiornamento: Maggio 2026

**1. Informazioni generali**
SocialPegliBot ("il Bot") è uno strumento di automazione interno sviluppato per gestire e pubblicare contenuti sui canali social ufficiali (Facebook, Instagram, YouTube, TikTok) legati alla struttura ricettiva di Genova Pegli.

**2. Raccolta dei dati**
Il Bot NON raccoglie, NON memorizza e NON processa dati personali di utenti esterni o del pubblico. Non esiste un database di registrazione utenti.

**3. Utilizzo delle API di terze parti**
Il Bot utilizza le API ufficiali di TikTok, Meta (Facebook/Instagram) e Google (YouTube) esclusivamente per la pubblicazione automatizzata di contenuti multimediali (foto, video, testo) generati dall'amministratore.

**4. Contatti**
Per qualsiasi domanda relativa a questa policy, puoi contattare l'amministratore del sistema.
